# Organization and Group identification for Projects using the API

You can use the following API endpoints to find Snyk groups (GroupId) and organizations (Orgid):

* Get a group by GroupId: https://apidocs.snyk.io/?version=2024-09-03%7Ebeta#get-/groups/-group\_id-\
  (Get a group)
* List organizations you have access to: https://docs.snyk.io/snyk-api/reference/orgs#orgs\
  (List accessible organizations)
* Find a GroupId for a user: https://docs.snyk.io/snyk-api/reference/organizations-v1#orgs\
  (List all the organizations a user belongs to — use this to discover GroupId relationships)
* Request organizations in a group (by GroupId): https://docs.snyk.io/snyk-api/reference/orgs#groups-group\_id-orgs\
  (List all organizations in a group)
