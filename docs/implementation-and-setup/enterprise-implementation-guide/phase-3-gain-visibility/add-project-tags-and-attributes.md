# Add Project tags and attributes

After importing your Projects, you can add metadata using [Project attributes](/broken/pages/0QpK9cg1uNSiFdkvYO2r) or [Project tags](/broken/pages/dTk6mvDt9h4Q2PPDVLEC). This makes it easier to filter and report on specific subsets of your Organization.

For example, if you add both Project attributes including `frontend` and a tag of `Team:Unicorn` to all of your Projects that a specific Dev Team owns, you can easily generate a report of frontend critical vulnerabilities in production that team Unicorn owns.

Attributes and tags are also useful features that can be used to configure [Project collections and Project views](/broken/pages/kFyAmdY2hTpUgdEwfmlQ), making it easier for you to view Projects in a grouping that makes sense to you.
